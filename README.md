# Agenda Gabinete 247

Sistema completo de agenda com integração Google Sheets, chat em tempo real, PWA e notificações no Windows.

## 🚀 Funcionalidades

- 📅 Gestão completa de compromissos (CRUD)
- 🔍 Filtros por ano e mês
- 📍 Integração com Google Maps
- 💬 Chat entre usuário e administrador
- 🔔 Notificações em tempo real (som + visuais)
- 📱 PWA (instalável como aplicativo)
- 🪟 Notificações nativas no Windows
- 🔐 Login administrativo seguro
- 📊 Dados persistidos no Google Sheets

## 🛠️ Tecnologias

- HTML5 / CSS3 / JavaScript
- Google Apps Script
- Google Sheets API
- Service Worker (PWA)
- Push API (notificações)
- SweetAlert2

## 📋 Configuração

### 1. Google Sheets
1. Crie uma planilha no Google Sheets
2. Extensões → Apps Script
3. Cole o `code.gs`
4. Execute `executarSetup()`
5. Publique como Web App

### 2. Aplicação Web
1. Substitua `SEU_SCRIPT_ID` no `index.html`
2. Faça upload para GitHub Pages, Vercel ou Netlify

### 3. Ícones PWA
Use o gerador de ícones incluso ou gere manualmente na pasta `/icons/`
